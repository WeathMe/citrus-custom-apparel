# Citrus Custom Apparel

Static website matching the approved forest-green and orange mockup. Twelve pages, responsive navigation, SEO titles/descriptions, sitemap, and accessible quote email composer.

## Cloudflare Pages
Connect a dedicated GitHub repository. Framework preset: None. No build command. Build output directory: dist. Add citruscustomapparel.com and www through Pages Custom domains. Preserve all SiteGround MX, SPF, DKIM and DMARC records. Existing root parking A records must be replaced when Pages connects the apex, not the email records.

## Preview
Run `python -m http.server 8080 --directory dist` from this folder, then visit http://localhost:8080.
